Mã của bạn · Your code

Dán mã này vào trang quản trị OpenTenki, ô "Mã uỷ quyền" trong khung Tài khoản Threads, rồi bấm Xác nhận.

Paste this code into the OpenTenki admin panel ("Authorization code" in the Threads account box), then click Connect.

Mã hết hạn sau vài phút và chỉ dùng được một lần.

The code expires in a few minutes and works only once.

Chưa có mã · No code yet

Trang này chỉ hiện nội dung khi Threads chuyển hướng về đây kèm tham số code. Mở thẳng thì không có gì để hiện.

This page only shows something when Threads redirects here with a code parameter.

Threads từ chối · Threads declined

Thường là do bạn bấm Huỷ, hoặc địa chỉ chuyển hướng chưa khớp cấu hình trong bảng điều khiển của Meta.

Usually because access was cancelled, or the redirect address does not match the Meta app settings.
